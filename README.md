# opencode-antiplagiat-plugin

Плагин [OpenCode](https://opencode.ai), который проверяет тексты (рефераты, курсовые,
главы, статьи — любые) на **антиплагиат и ИИ-контент сразу на трёх сайтах, бесплатно
и параллельно**:

| Сайт | Что даёт результат | Бесплатный лимит |
|---|---|---|
| **ap-vuz.ru** (АП ВУЗ, демо-отчёт) | Оригинальность, заимствования, цитирования, самоцитирования, **ИИ-контент** | до 2000 символов за проверку |
| **killer-antiplagiat.ru** (Антиплагиат Киллер) | Уникальность, заимствования + список найденных источников с процентами | до 1000 символов, **не чаще 5 проверок в сутки** (лимит по IP) |
| **ai-texts.ru** (Глубокий AI-анализ) | Вероятность «ИИ-контента» по 20 признакам с разбором каждого | весь текст (лимит 120 000 симв.) |

Используются ссылки с параметром `etext`, открывающие **бесплатный тариф** — ни оплаты,
ни регистрации, ни API-ключей не требуется. Проверка идёт через фоновый headless-браузер
(Playwright/Chromium), как это сделал бы обычный пользователь.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `antiplagiat_ap_status` | Состояние моста: запущен ли, какие сайты доступны. Сам поднимает мост |
| `antiplagiat_check` | Проверяет текст на всех трёх сайтах и возвращает проценты + готовую сводку |

(Имена в OpenCode отображаются без префикса — `ap_status` и `check`; `ap_status` выбрано
специально, чтобы не перекрывать одноимённый `status` плагина DeepSeek.)

Параметры `antiplagiat_check`:

- `text` — полный текст работы;
- `sites` — проверять не всё, а конкретные сайты: `apvuz`, `killer`, `aitexts`;
- `samples` — сколько фрагментов проверить на сайтах с лимитом: `1` (по умолчанию) —
  только начало текста, `3` — **начало/середина/конец с усреднением** (рекомендуется
  для курсовых и рефератов, чтобы оценка была по всей работе, а не по введению);
- `timeout` — сколько секунд ждать результат одного сайта (30–600, по умолчанию 180).

Примеры запросов агенту:

- «Проверь этот текст на антиплагиат по трём сайтам»;
- «Прогони курсовую целиком (samples=3) и покажи проценты»;
- «Какой процент ИИ-контента у введения?».

## Как это работает

```
OpenCode (агент)
   │  инструменты antiplagiat_*  (index.ts)
   ▼
Локальный HTTP-мост  http://127.0.0.1:8778   (Python + FastAPI + Playwright)
   │  три постоянных headless-профиля браузера (по одному на сайт)
   ▼
ap-vuz.ru · killer-antiplagiat.ru · ai-texts.ru   (бесплатные тарифы)
```

Мост поднимается плагином автоматически при первом вызове и держит тёплые профили,
поэтому повторные проверки идут быстрее. Первый полный прогон по трём сайтам занимает
около **50 секунд**, `samples=3` — около 2,5 минут (сайты работают параллельно).

## Установка

Нужны Windows, Python 3.10+ и OpenCode V2.

1. Скачайте/скопируйте эту папку (или склонируйте репозиторий).
2. Установите зависимости моста — запустите **`install.ps1`** (правый клик →
   «Запуск с помощью PowerShell»).
3. Добавьте плагин в свой конфиг OpenCode — `~/.config/opencode/opencode.json`
   (глобально) или `opencode.json` проекта:

   ```jsonc
   {
     "$schema": "https://opencode.ai/config.json",
     "plugins": [
       "C:/Полный/Путь/К/opencode-antiplagiat-plugin"
     ]
   }
   ```

4. Перезапустите OpenCode (`opencode service restart` или просто перезапустите редактор).

Готово. При первом вызове `antiplagiat_check` агент сам поднимет мост и пришлёт
проценты по трём системам.

## Устранение неполадок

- **Мост не стартует** — запустите `install.ps1` вручную и посмотрите `bridge/bridge.log`.
  Порт у плагина свой: **8778** (мост DeepSeek — 8777, мост надстройки Word — 8765).
- **Одна из проверок не удалась** — в ответе будет `ok: false` и текст ошибки конкретного
  сайта; повторите вызов. Сайты иногда перегружены (АП ВУЗ обещает «от 3 секунд до 5 минут»).
- **Селекторы перестали работать** — это веб-автоматизация, после редизайна сайта
  обновите соответствующую функцию в `bridge/antiplagiat_bridge.py`
  (`_apvuz_one`, `_killer_one`, `_aitexts_one`, `parse_*`).
- **Порт занят** — остановите старый мост: `POST http://127.0.0.1:8778/shutdown`.

## Важно знать

- **Антиплагиат Киллер разрешает 5 бесплатных проверок в сутки на один IP.** Когда лимит
  исчерпан, сайт показывает модалку «Бесплатная проверка доступна 5 раз в сутки» — плагин
  ловит её и сразу возвращает понятную ошибку, не тратя время на ожидание (лимит
  сбрасывается на следующий день). Поэтому на длинной работе (samples=3) у Киллера
  успевает уйти 3 из 5 проверок за день.
- Бесплатные тарифы ограничены по объёму (см. таблицу сверху): для длинных работ
  используйте `samples=3`, тогда проверяются три фрагмента и результат усредняется.
  В ответе всегда указано, сколько символов реально проверено (`chars_checked`,
  поле `truncated`, если текст не влез в лимит).
- На ai-texts.ru счётчик бесплатных проверок хранится в `localStorage` браузера —
  мост очищает его перед проверкой, поэтому этот сайт работает без ограничений.
- Результаты — это **демо-проверка**, а не преподавательский отчёт из закрытой системы
  АП ВУЗ: цифры ориентировочные (обычно близко к университетским, но не гарантируются).
  Относитесь к ним как к быстрой предварительной оценке.
- Автоматизация веб-страниц «хрупкая»: после редизайна сайтов селекторы придётся
  поправить — всё локально в одном файле моста.
